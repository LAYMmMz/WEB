BEHIND THE PROJECT / 02

Built for curiosity.

SkyTrace is an educational aviation website created for a collaborative version-control activity. It visualizes how cities are connected across the globe.

01 / EXPLORE

Interactive globe

Rotate the globe and observe animated arcs connecting airport cities.

02 / DISCOVER

Route directory

Search six sample connections by city name or airport code.

03 / LEARN

Static technology

HTML, CSS and JavaScript power the site without an account, database or API key.

About the data

All flight movements are illustrative simulations. The visualization does not report actual aircraft locations, schedules, delays or airline operations.

Project source

Our interface takes inspiration from animated globe designs such as Aceternity UI. This implementation uses a custom Canvas globe for static hosting.
